Honest, by design
Two real SPY-2026 model versions have gone through this gate live so far — both registered, neither cleared it (mean_lift −0.140 on 08-20, −0.115 on 08-21). That's not a bug in the page, it's the actual, current, disclosed state of the model — see fig. 2's "Model Registry" node: every run gets logged whether it passes or not. This count is a point-in-time snapshot — for the current, always-fresh count and full real test output, see the ML Signal Model page, regenerated from the live track_record.jsonl daily.
